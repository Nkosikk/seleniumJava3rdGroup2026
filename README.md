# API Assessment 2026

## Overview
This project is an API automation framework built using Java, Rest Assured, TestNG, Maven, and Allure Reports.

## Technologies
- Java 17
- Maven
- Rest Assured
- TestNG
- Allure

## Test Scenarios
### Login API
- Successful Login
- Invalid Login

### Courses API
- Get Published Courses

### Announcements API
- Create Announcement
- Get Announcement
- Update Announcement
- Delete Announcement
- Verify Deleted Announcement
- Negative Test

## Running the Tests

Run all tests:

```bash
mvn clean test
